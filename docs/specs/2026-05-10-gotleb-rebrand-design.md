## 1. Brief

GOTLEB — российский бренд обуви ручной работы из натуральной кожи (мужская + женская). Текущий сайт сделан на Tilda, выглядит как типовой шаблон: Montserrat, бежевый `#eeeeee`, плотная сетка карточек — без характера бренда. Андрею нужен ребрендинг сайта в стиле fashion-брендов с показом вариантов.

Цель прототипа — дать Андрею **живой URL**, в браузере которого он может пройтись по 4-м экранам и принять направление. Прототип не закрывает корзину, оплату, личный кабинет — это потом, поверх Tilda или нового стека.

**Стек:** чистый HTML + CSS + ванильный JS. Без билд-степа, без npm, без фреймворков.

**Локально:** открыть `index.html` напрямую или `python3 -m http.server 8000`.

**Хостинг:** новый репозиторий `vasiliiberezinart-ops/gotleb-rebrand` → GitHub Pages → `https://vasiliiberezinart-ops.github.io/gotleb-rebrand/`. Андрей открывает URL и смотрит. Деплой — git push (паттерн bezobrazov / microcredit / man-from-bread / oleg-glushkov).

**Шрифты (бесплатные близнецы платных):**
- `Cormorant Garamond` (Google Fonts) — отыгрывает GT Sectra Italic
- `Inter` (Google Fonts) — отыгрывает Söhne / Neue Haas Grotesk
- `JetBrains Mono` (Google Fonts) — для ASCII-перебивок T2

Если Андрей купит лицензии на GT Sectra / Editorial New / Söhne — заменим в одном месте (`tokens.css`).

**Фото:**
1. Скачать все `tildacdn.com/...` ссылки с `https://gotleb.ru/`, `/all`, `/man`, `/woman`, `/about`
2. Положить в `assets/photos/`, оригинальные имена сохранить
3. Применить CSS-фильтр на уровне `.photo` класса:
   ```css
   filter: sepia(0.12) contrast(0.96) saturate(0.92) brightness(1.02);
   ```
4. Поверх — псевдоэлемент `::after` с `background-image: url('grain.svg'); opacity: 0.06;`

Если фото не хватит на about (например, секция «Шов» требует фото процесса) — оставить заглушку-плейсхолдер `[ photo from atelier ]` с hairline-рамкой, пометить в README.

## 4. Design System

### 4.1 Палитра (`tokens.css`)

```css
:root {
  --paper:      #ece7df;   /* фон бумаги, основной */
  --paper-deep: #e2dcd0;   /* фон карточек, hover-подсветка */
  --ink:        #2b2620;   /* основной текст, тёмный шоколад */
  --ink-soft:   #5a5247;   /* подзаголовки, метаданные */
  --ink-faint:  #948b7d;   /* подписи, цены-через */
  --rule:       #c9c1b3;   /* hairline-разделители */
  --accent:     #a06a3c;   /* кожаный, тонко — только для sale-цены и одной-двух ссылок-эмфаз */
}
```

Семь оттенков. Никаких ярких CTA-кнопок, никаких гради ентов, никаких свечений.

### 4.2 Типография

| Роль | Шрифт | Размер | Вес | Tracking | Использование |
|---|---|---|---|---|---|
| Hero / манифест | Cormorant Garamond Italic | 64–96px | 400 | 0 | `<h1>` главной, секционные заголовки About |
| H2 секции | Cormorant Garamond | 36–48px | 500 | 0 | «Коллекция», «Материалы», «Похожие пары» |
| H3 / лейбл категории | Inter | 14px | 500 | 0.18em uppercase | «МУЖСКАЯ», «ЖЕНСКАЯ», nav |
| Body | Inter | 15–16px | 400 | 0 | Описания, манифест-абзацы |
| Цитата (только Андрея) | Cormorant Garamond Italic | 22–28px | 400 | 0 | Манифест-блок, фраза в карточке товара |
| UI / nav / цена | Inter | 13–14px | 500 | 0 | Меню, корзина, ценники, размеры-pills |
| Caption / sku / sub-meta | Inter | 11px | 400 | 0.12em | Артикул, метаданные внутри Inter-блоков |
| **ASCII-перебивка** | **JetBrains Mono** | **12px** | **400** | **0.04em** | **ТОЛЬКО Q1-перебивки между секциями** |

### 4.3 Сетка и ритм

- Max content width: `1400px`
- Колонок: 12, gutter `32px` desktop / `16px` mobile
- Контент-колонка для текстов (манифест, about): 6 кол по центру
- Каталог: 3 колонки desktop / 2 tablet / 1 mobile
- Базовая единица: `8px`
- Между секциями: `120px` desktop / `64px` mobile
- Внутри секции: `48px` / `24px`

### 4.4 «Архивный слой» (что отличает от чистого Arket)

1. **ASCII-перебивки T2** между секциями:
   ```
   ┌─ collection ─────────────────────────────────────┐
   │ GOTLEB · Hand-stitched · Calf · 04 pairs · SS26 │
   └──────────────────────────────────────────────────┘
   ```
   - JetBrains Mono 12px tracking 0.04em
   - Цвет `--ink-soft`
   - Max-width 640px, по центру
   - Поля 80px сверху и снизу
   - **Только реальные поля бренда** (модель / шов / материал / артикул / город / сезон). Если поле неизвестно — заглушка `[ city ]`, `[ season ]`, не выдумывать.

2. **Sepia-overlay** на всех фото (`filter` + grain `::after`)

3. **Hairline-разделители** `1px solid var(--rule)` вместо толстых линий

4. **Курсивные обозначения** в подвалах секций — Cormorant Italic 13px (`atelier`, `since [ year ]`, etc.)

### 4.5 Состояния

| Состояние | Поведение |
|---|---|
| Hover на ссылке | Подчёркивание прорисовывается слева направо (200ms) |
| Hover на карточке товара | Cross-fade на вторую фотографию (400ms) + фон `--paper-deep` |
| Focus | `outline: 1px solid var(--ink); outline-offset: 4px;` |
| Active size-pill | Заливается `--ink`, текст `--paper` |
| Disabled | `opacity: 0.4; cursor: default;` |

Без ярких кнопок. CTA — это hairline-link с курсивом, не плашка.

## 6. Контент-заглушки от Андрея

Прототип ставит тексты-заглушки в стиле бренда (на русском, с английскими лейблами в перебивках где это уместно). Все заглушки помечены `[ ... ]` в HTML-комментариях. Андрей при review правит.

| Поле | Где | Объём | Пример заглушки |
|---|---|---|---|
| Hero-фраза главной | главная hero | 1 строка ≤8 слов | `[ Обувь, которая помнит руку ]` |
| Манифест-блок | главная + about | 2-3 фразы ≤40 слов | `[ GOTLEB — это ... ]` |
| Город мастерской | все перебивки | 1 слово | `[ Москва ]` или `[ Moscow atelier ]` |
| Год основания | about-перебивка | 4 цифры | `[ 2018 ]` |
| Пар в месяц | about-перебивка | число | `[ ~20 ]` |
| Тип шва | about + product specs | 1-2 слова | `[ goodyear ]` / `[ blake ]` / `[ hand-stitched ]` |
| Описания материалов | about | 3 блока × 2-3 строки | Calf / Suede / Cordovan |
| Описание шва | about | 3-4 строки | про метод и время |
| Описание пути пары | about низ | 1-2 фразы | про время изготовления |
| Описания моделей | каждая product-карточка | 2-3 строки на пару | про конкретный Oxford / Derby / Loafer |
| Адрес мастерской | about + footer | 1 строка | если есть |

## 7. Скоуп — что НЕ делаем в этом прототипе

- Корзина, добавление в корзину, оплата (только UI без логики)
- Личный кабинет / аутентификация
- Реальная отдача товаров — каталог захардкожен в HTML, без CMS / админки
- Поиск (иконка `⌕` есть в шапке, открывает модал-заглушку или dummy-поле)
- Newsletter-форма (форма есть, отправка не настроена — это `<form action="#">` или mailto:)
- Многоязычность (только RU. EN-лейблы только в ASCII-перебивках для архивной эстетики)
- Доставка / расчёт стоимости / интеграция с СДЭК
- А/B варианты — мы выбрали одно направление

Эти задачи — следующий этап, когда Андрей одобрит направление и решит, мигрировать с Tilda или оставить.
